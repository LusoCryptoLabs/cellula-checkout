How to pay

  1. Have a Cellula wallet at wallet.testnet.cellula.id. Its Fiber balance pays; the first payment can top it up.
  2. Pick something here and press Pay with Fiber. Your Cellula wallet opens in a small window; confirm there. No other tab is needed.
  3. The shop's own server confirms the payment. This page never takes the window's word for it.

How this shop takes Fiber

The shop's server makes each invoice from its own channel with the merchant kit, and learns it was paid from a signed webhook, the way Stripe sends them.

// server: an invoice for the order
const inv = await merchant.createInvoice({ amount_ckb: '2', order_id: order.id })

// page: the button opens the person's checkout
<script src="https://testnet.cellula.id/pay-with-fiber.js"></script>
<button data-fiber-invoice="${inv.invoice}">Pay with Fiber</button>

// server: believe a payment only from a signed webhook
if (verifyWebhook(rawBody, req.headers['fiber-signature'], secret)) markPaid(...)
